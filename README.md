# Abobaker Ali — QA Portfolio

A modern, responsive QA/SDET portfolio built with React, TypeScript, Vite and Lucide icons.

## Included

- Responsive one-page portfolio
- Hero / About / Skills / Projects / Experience / Certifications / Contact
- Interactive project detail modal
- Mobile navigation
- Playwright/Pytest automation showcase
- Dark QA-engineering visual style
- No employer-confidential information
- Ready for Vercel, Netlify or GitHub Pages-style static hosting

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## Personalize before publishing

Edit `src/App.tsx`:

1. Replace `YOUR_EMAIL@example.com`.
2. Replace the LinkedIn URL.
3. Replace the GitHub URL.
4. Update project descriptions with public GitHub repositories when available.
5. Add your real CV link if desired.
6. Add a professional headshot only if you want one.

## Important

Do not publish confidential screenshots, internal URLs, source code, credentials, test data, client information or proprietary architecture from employer projects.
